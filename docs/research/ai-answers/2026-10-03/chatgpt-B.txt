Question B: What's the best way to send a screenshot from my Mac to a coding agent running on a remote server?

If the coding agent can access files on the remote server, the simplest reliable workflow is:

Take the screenshot on your Mac — ⌘⇧4 or ⌘⇧5.

Save it to a known file, e.g. ~/Desktop/screenshot.png.

Copy it to the server with scp:

scp ~/Desktop/screenshot.png user@server:/tmp/screenshot.png


Tell the coding agent to inspect /tmp/screenshot.png.

If you're already using SSH, an even nicer option is dragging the screenshot into an SFTP client or using rsync for repeated transfers.

For a coding agent, I'd generally recommend PNG → scp → a predictable path on the server. It avoids clipboard/GUI integration and gives the agent a real file it can inspect with its image tools.
