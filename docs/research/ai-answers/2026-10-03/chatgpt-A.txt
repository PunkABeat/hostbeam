Question A: How do I paste a screenshot into Claude Code when it's running on a remote server over SSH?

--- Answer (verbatim innerText) ---

If Claude Code is running on a remote server over SSH, your local screenshot isn't automatically available to the remote terminal. The easiest approach is to upload the screenshot to the server, then give Claude Code the file path.

Recommended: upload the screenshot with scp

On your local machine:

scp ~/Desktop/screenshot.png user@your-server:~/screenshot.png


Then, in your SSH session:

claude


and tell Claude:

Please look at ~/screenshot.png


Claude Code can then inspect the image from the remote filesystem.

If you want to copy/paste directly

If your terminal supports clipboard image transfer (for example, some modern terminal emulators), pasting may work locally but SSH itself doesn't transmit an image clipboard. The remote shell generally receives text, not the actual image data.

A convenient workflow is:

# local
scp screenshot.png user@server:/tmp/screenshot.png


Then:

Look at /tmp/screenshot.png and tell me what's wrong.

Even easier for repeated screenshots

You can use rsync:

rsync -av screenshot.png user@server:/tmp/


Or, if you're taking screenshots repeatedly, set up a small local command/shortcut that uploads the current screenshot to a fixed remote path, e.g. /tmp/current.png. Then you can repeatedly tell Claude:

Inspect /tmp/current.png
