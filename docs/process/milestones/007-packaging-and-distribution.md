# Milestone 007: Packaging & Distribution

Status: In progress (opened 2026-07-04). Works through
[packaging-checklist.md](../packaging-checklist.md); ADR 0008 fixed the shape
(Developer ID signed + notarized, outside the App Store, no App Sandbox).

## Goal

A downloadable, signed, notarized Hostbeam.dmg with in-app auto-updates, served
from download.hostbeam.app — the last mile between the finished licensing
system and actual customers.

## Decisions (owner, 2026-07-04)

- **Auto-updates: yes** — Tauri updater plugin. Also what makes the paid
  1-year update window enforceable (ADR 0014).
- **Minimum macOS: 13.0 (Ventura)** — matches the marketing claims.
- **Artifacts on Cloudflare R2** — bucket `hostbeam-releases` behind
  `download.hostbeam.app` (stable `/Hostbeam.dmg` + versioned paths +
  `latest.json`). Same account as the worker and zone.
- **Code on a private GitHub repo** — pushed 2026-07-04; the repo previously had no remote at all.
- **Apple Developer Program: individual** enrollment submitted 2026-07-04,
  **approved 2026-07-07** (Team ID `U3C6XC6LHJ`); convert to the company
  later once its D-U-N-S number exists (requested in parallel — conversion
  keeps the account and doesn't invalidate shipped builds).

## Done so far (pre-certificate work)

- Bundle metadata in `tauri.conf.json`: publisher/copyright/category
  (DeveloperTool), short/long descriptions, `minimumSystemVersion` 13.0,
  targets narrowed to `app` + `dmg`.
- `scripts/check-version-sync.mjs` — release guard keeping tauri.conf.json
  (source of truth), Cargo.toml, and package.json on one version.
- `scripts/release-macos.sh` — the staged release pipeline: version check →
  universal build → (Tauri-integrated) sign + notarize → `spctl` verify →
  updater `latest.json` → R2 upload. Env-driven; no secrets in the repo.
