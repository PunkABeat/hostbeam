# Milestone 001: Documentation Foundation

Status: Complete.

## Goal

Create the documentation foundation and repository structure needed before implementation starts.

## Scope

- Create top-level project README.
- Create repository agent instructions.
- Capture product concept and product boundaries.
- Capture initial experience direction.
- Capture engineering constraints.
- Create research question backlog.
- Create live progress tracking.
- Create agent handoff files.
- Create ADR index and initial ADRs.
- Initialize git and commit the documentation foundation.

## Out Of Scope

- Flutter scaffold.
- Dependency installation.
- App source code.
- Generated project files.
- Clipboard image reading.
- Remote upload.
- Hotkeys.
- Menu-bar behavior.
- Notifications.
- Saved hosts.
- Recent history.

## Acceptance Criteria

- Required documentation files exist.
- ADRs capture durable decisions.
- `docs/process/progress.md` identifies this milestone as current.
- `docs/agents/current-handoff.md` is short and points to the next task.
- No stale references to unrelated prior projects, frameworks, or build histories.
- Git repository exists.
- Documentation foundation is committed.
