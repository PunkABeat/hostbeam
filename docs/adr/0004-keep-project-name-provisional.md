# ADR 0004: Keep Project Name Provisional

Status: Superseded by ADR 0015 (Hostbeam is the final name).

Date: 2026-06-14.

## Context

The repository needs a working name, but product naming has not gone through a clearance pass.

## Decision

Treat `<PROJECT_NAME>` as provisional until a naming clearance pass is completed. Hostbeam is the working name for the repository and documentation.

## Consequences

- User-facing naming can change before implementation or release.
- Documentation should avoid assuming naming clearance has happened.
- A later ADR or product decision should record the result of the naming clearance pass.
